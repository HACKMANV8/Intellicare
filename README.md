# Intellicare
intellicare from amc engineeing college

The healthcare sector struggles to provide continuous monitoring and timely intervention, especially for elderly and disabled individuals at higher risk.
Traditional systems are hospital-centered or require frequent manual checkups, making them inconvenient, time-consuming, and often ineffective in detecting real-time emergencies.
Existing wearables often lack: Seamless integration, User-friendly interfaces, Reliable real-time communication
There is no centralized platform to securely collect, analyze, and display health data while ensuring quick pairing and easy accessibility.
Hence, there is a need for an IoT-enabled smart wearable system integrated with a web app to:
 Enable continuous health monitoring
 Provide real-time emergency alerts
 Ensure secure and accessible health data sharing
